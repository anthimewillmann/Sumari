# AI Website Summarizer

AI Website Summarizer is a Safari browser extension built with Swift that uses Apple Intelligence to generate concise summaries of any webpage directly within Safari.

The extension helps users quickly understand articles, blog posts, documentation, and other web content without reading the entire page.

## Features

- Summarize any webpage with a single click
- Powered by Apple Intelligence
- Fast and privacy-focused on-device processing
- Clean and lightweight Safari integration
- Native Apple ecosystem experience
- Designed for productivity and efficient reading

## Tech Stack

- Swift
- SwiftUI
- Safari Web Extensions
- Apple Intelligence
- Xcode
- macOS Development

## Installation

bash git clone https://github.com/anthimewillmann/AI-Website-Summarizer.git 

1. Open the project in Xcode
2. Build and run the macOS app
3. Enable the Safari Extension in Safari Settings
4. Start summarizing webpages

## How It Works

The extension extracts the content of the currently active webpage and leverages Apple Intelligence to generate a clear and concise summary. The result is displayed directly inside Safari, allowing users to quickly understand the most important information from any page.
