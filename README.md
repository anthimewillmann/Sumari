# Sumari

Sumari is a Safari browser extension that uses Apple Intelligence to instantly summarize any website.

Built with Swift, Safari Extensions, and Apple's Foundation Models framework, Sumari helps users quickly understand articles, blog posts, and web content without reading the entire page.

## Features

- AI-powered website summaries
- Powered by Apple Intelligence
- Automatic language detection
- Summaries in the original language
- Native Safari integration
- Fast and lightweight

## Tech Stack

- Swift
- SwiftUI
- Safari Web Extensions
- Foundation Models
- Apple Intelligence

## Installation

bash git clone https://github.com/anthimewillmann/Sumari.git 

Open the project in Xcode, build it, and enable the Safari extension in Safari Settings.

## Motivation

Sumari was created as a personal project to explore Apple Intelligence and Safari Extension development while building a useful productivity tool for everyday web browsing.
